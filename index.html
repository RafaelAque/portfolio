HCI Project

FellowshipHub is an HCI-focused project designed around making fellowship management easier to understand, navigate, and use. The interface emphasizes clear user flows, readable dashboard sections, and straightforward actions so users can quickly find the information they need without feeling overwhelmed.

This project highlights my interest in human-centered design by balancing functionality with usability. I focused on making the system feel organized and approachable while still supporting practical tasks through a clean dashboard experience.
